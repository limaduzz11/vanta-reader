# Security Policy

## Supported Versions

Only the latest release branch of VANTA Reader receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

We take the security and privacy of our users seriously. If you believe you have found a security vulnerability in VANTA Reader:

1. **Do not disclose the issue publicly.** Please do not open public GitHub issues or discussions regarding suspected vulnerabilities.
2. Report the vulnerability privately via **GitHub Private Vulnerability Reporting** (available under the **Security** tab of the repository) or contact the maintainer directly.
3. Please include:
   - A detailed description of the vulnerability.
   - Steps to reproduce the issue or a proof of concept.
   - The potential impact on users or devices.

We will acknowledge receipt of your report within 48 hours and work with you on a coordinated disclosure timeline.
